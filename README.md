# Support-Calibrated Evidence Transport

Current experiments, source code and result tables are in [r2/](r2/README.md).

The [complete numerical reproduction release](https://github.com/Heinrichx26/support-calibrated-evidence-transport/releases/tag/r2-complete-2026-10-15), together with the [original R2 archive](https://github.com/Heinrichx26/support-calibrated-evidence-transport/releases/tag/r2-2026-10-15), supplies the code and saved numerical inputs for Tables 1-4 and S1-S37. Follow [REPRODUCE_ALL_TABLES.md](r2/REPRODUCE_ALL_TABLES.md) for the six-archive extraction order, SHA-256 checks and smoke/full table-export commands. All 41 table CSVs have been reconstructed byte for byte. [Additional validation](r2/README_ADDITIONAL_VALIDATION.md) documents the list-feature controls, conditional-risk calibration, refitted conflict ablations and independent FEVER refit.

The [independent FEVER confirmation](r2/README_INDEPENDENT_CONFIRMATION.md) supplies 3,000 new evaluation claims, 600 separate calibration claims, frozen list and evidence-set models, all four primary comparisons and the full numerical reconstruction. Tables S36–S37 and their complete records are in `R2_independent_confirmation.zip` on the complete release.

The experiments include frozen HealthVer and COVID-Fact calibration, declared comparisons and ablations, complete evidence-set stratification, and the S31 comparison of sentence ordering and per-query admission counts. Saved exploratory trials, including unsuccessful trials, remain available. Source documents and pretrained neural weights are obtained from their pinned original providers.

The root `src/`, `results/`, `tests/` and `figures/` retain historical material. Use the `r2/` instructions for the current experiments. Earlier releases and history remain available.
