Current experiments, source code and result tables are in [r2/](r2/README.md).

The [complete numerical reproduction release](https://github.com/Heinrichx26/support-calibrated-evidence-transport/releases/tag/r2-complete-2026-10-15), together with the [original R2 archive](https://github.com/Heinrichx26/support-calibrated-evidence-transport/releases/tag/r2-2026-10-15), supplies the code and saved numerical inputs for Tables 1-4 and S1-S31. Follow [REPRODUCE_ALL_TABLES.md](r2/REPRODUCE_ALL_TABLES.md) for the four-archive extraction order, SHA-256 checks and smoke/full table-export commands. The experiments include frozen HealthVer and COVID-Fact calibration, declared comparisons and ablations, complete evidence-set stratification, and the S31 comparison of sentence ordering and per-query admission counts. Saved exploratory trials, including unsuccessful trials, remain available. Source documents and pretrained neural weights are obtained from their pinned original providers.

The root `src/`, `results/`, `tests/` and `figures/` retain historical material. Use the `r2/` instructions for the current experiments. Earlier releases and history remain available.
