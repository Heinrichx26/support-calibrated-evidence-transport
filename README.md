# Support-Calibrated Evidence Transport

This repository contains reproducibility materials for the manuscript **Support-Calibrated Evidence Transport for Evidence-Grounded Review Support**.

The repository focuses on the Support-Calibrated Evidence Transport (SCET) evaluation layer used in the manuscript. SCET constructs certificate objects for admitted evidence, selects admission settings on calibration queries, and reports evidence quality under workload-aware admission constraints.

## Repository contents

- `src/`: experiment code for candidate construction, cross-domain evidence retrieval, SCET admission, open-pool audit, conflict-pressure audit, retrieval-verification diagnostics, and figure generation.
- `tests/`: lightweight unit tests for schema checks, calibration separation, certificate construction, audits, and figure helpers.
- `results/`: derived summary tables used to check the manuscript tables and figures. Large candidate-detail files are excluded.
- `figures/`: final manuscript figure files in review-friendly formats.
- `data/DATA_SOURCES.md`: source and placement instructions for public datasets.

## Data policy

Raw datasets are not stored in this repository. The scripts use public data sources and place reconstructed files under `data/raw_open/evidence_retrieval/` and `data/interim/evidence_retrieval/`. These folders are ignored by Git because they can contain large downloaded or reconstructed files.

Included result files are derived summaries, audit tables, model summaries, and certificate records needed to inspect the reported evidence-admission behavior without uploading multi-gigabyte candidate pools.

## Environment

Python 3.10 or later is recommended.

```bash
python -m pip install -r requirements.txt
```

Optional neural scoring and verification runs require `sentence-transformers`, `torch`, and `transformers`. Lexical smoke runs and included summary checks can run without downloading neural models.

## Quick checks

```bash
PYTHONPATH=src python -m unittest discover -s tests
```

On Windows PowerShell:

```powershell
$env:PYTHONPATH="src"; python -m unittest discover -s tests
```

## Reconstruct candidate pools

SciFact and FEVER can be downloaded by the adapter. HoVer and BTS require the public source files described in `data/DATA_SOURCES.md`.

```bash
python src/ipm_evidence_dataset_adapters.py --dataset scifact --mode smoke --candidates-per-query 50
python src/ipm_evidence_dataset_adapters.py --dataset fever --mode smoke --candidates-per-query 50
```

## Run SCET and comparison audits

Smoke runs are intended for installation checks.

```bash
python src/ipm_cross_domain_evidence_benchmark.py --mode smoke --datasets scifact,fever --candidates-per-query 50 --fast-text-scores
python src/ipm_scet_evidence_transport.py --mode smoke --datasets scifact,fever --candidates-per-query 50 --fast-text-scores
python src/ipm_scet_open_pool_audit.py --mode smoke --datasets scifact,fever --candidates-per-query 100 --fast-text-scores
python src/ipm_credot_evidence_transport.py --mode smoke --datasets scifact,fever --candidates-per-query 50 --fast-text-scores --fast-prior
```

The retrieval-verification diagnostics operate on a SCET detail file. The repository includes summary outputs, while full detail files can be regenerated by the SCET scripts.

```bash
python src/ipm_scet_risk_reduction_audit.py --detail results/ipm_scet_full/scet_detail.csv
python src/ipm_scet_nli_verification.py --detail results/ipm_scet_full/scet_detail.csv --datasets scifact --max-queries-per-dataset 50
```

## Regenerate figures

```bash
python src/make_ipm_scet_figures.py
python src/make_ipm_added_review_figures.py
```

The scripts write figure outputs to `figures/`.
